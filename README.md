## Katalon Automation Project

## Project Overview

Project ini berisi automation testing berbasis Katalon Studio untuk menguji fitur pada Website AI Care Backoffice
Tujuan project ini adalah untuk memastikan seluruh fitur berjalan sesuai requirement melalui skenario pengujian otomatis.

## Tech Stack
| Komponen       | Versi                 |
| -------------- | --------------------- |
| Katalon Studio | v10                   |
| Groovy         | Built-in              |
| Platform       | Website               |
| OS             | Windows / Mac / Linux |

## Project Structure

- Test Cases → Kumpulan test case sesuai dengan modul menu
- Test Suites → Kumpulan eksekusi test suite
- Test Suite Collection → Eksekusi paralel / batch
- Object Repository → Kumpulan locator/object sesuai dengan modul menu
- Keywords → Custom keywords
- GlobalVariable → Global configuration variable

## Setup & Installation

- Install Katalon Studio
- Clone repository ini https://github.com/arjunsetyawan/Katalon-Web-AICare-Project.git
- Buka menggunakan Katalon Studio
- Update Execution Profile bila diperlukan (contoh: URL, credentials, timeout)

## Cara Menjalankan Test
**Menjalankan lewat Katalon (GUI)**

- Buka menu Test Case
- Pilih test case yang ingin dijalankan
- Klik Run
